この実験について

AIと一緒に数日かけて1本のゲームを作る——そんな制作を続けるうちに、ひとつの疑問が浮かびました。
「シンプルなゲームなら、人がまったく手を出さなくてもAIだけで作れるのでは？」

ルール

  1. お題（ジャンル × ひねり × テーマ）はプログラムがランダムに出します。
  2. 企画・コーディング・修正はすべてAIが行います。人はコードに触れません。
  3. すべてのゲームは PC とスマホの両方、日本語と英語の両方に対応します。自動テストで、PC（キーボードのみ）、スマホ（縦画面・タッチのみ）、言語の切り替えを検査し、合格したものだけが公開されます。不合格が続いた作品は破棄され、失敗として記録されます。
  4. 公開前に、制作したAI自身がPCとスマホの両方でゲームをプレイし、似ている作品をリサーチしたうえで自己採点します。
  5. すべての作品に、制作日時・制作AI（モデル名）・制作コスト（使用トークン数と金額換算）を記録します。

AIはどうやってプレイしているの？

ゲームの時計（アニメーションやタイマー）を止めた状態でスクリーンショットをAIに見せ、AIが決めた操作（「←を0.4秒押す」「画面のこの位置をタップ」など）の間だけ時間を進めます。これを繰り返すことで、AIは考える時間を気にせずアクションゲームもプレイできます。プレイの様子は各ゲームページの「AIのプレイログ」で見られます。

類似作品のリサーチ

ものづくりのアイデアは、完全な無から生まれることはありません。AIは自己採点の前にウェブで似ている作品やルーツになった作品を調べ、各ゲームページの「ルーツ・類似作品」に記録します。独創性の点数は、この調査結果を踏まえて付けられます。

制作コスト

AIが1本のゲームを作るのに使ったトークン数（入力・出力・キャッシュ）を集計し、制作時点のAPI定価で金額に換算して表示しています（日本語表示では円、英語表示ではドル）。実際の制作はサブスクリプションや無料枠の範囲で行っているため、追加の支払いは発生していません。AIの進化とともに「同じクオリティをいくらで作れるか」がどう変わるかも、この実験で見たいことのひとつです。

評価の項目

  • 遊んだ端末 — PC / スマホ・タブレット
  • 問題なく遊べたか — 問題なく遊べた / 不具合はあるが遊べた / 遊べなかった
  • 楽しさ（★1〜5）
  • クオリティ（★1〜5）— 見た目・操作感・完成度
  • 独創性（★1〜5）— アイデアの新しさ

AIも同じ項目で自己採点しています。「総合」は楽しさ・クオリティ・独創性の平均です。AIの感じ方と人間の感じ方の差も、この実験で見たいもののひとつです。

参加するAI

当面は Anthropic の Claude を中心に制作していますが、他社のAI（ChatGPT / GPT系、Gemini など）も同じお題・同じ仕様・同じテストで参加できる仕組みになっています。各作品の「制作AI」で、どのAIが作ったかを確認できます。

注意

  • ゲームはサイトから切り離された安全な環境（sandbox）で動いており、外部への通信や保存はできません。
  • 評価は匿名で集計されます。ブラウザごとに1作品1票で、あとから更新できます。
  • このサイトは無料のサービスだけで運営しています。容量を抑えるため、AIのプレイ画像は一部だけを圧縮して保存しています。
  • 初期の3作品はサイト構築中に作られたサンプルのため、ゲーム内の表示は日本語のみです。
ABOUT

About this experiment

After spending days building single games together with AI, a question came up:
"For simple games, couldn't AI make them entirely on its own — with no human touching anything?"

Rules

  1. A program picks a random prompt (genre × twist × theme).
  2. All planning, coding and fixing is done by AI. Humans never touch the code.
  3. Every game supports both PC and mobile, and both Japanese and English. Automated tests check PC (keyboard only), mobile (portrait, touch only) and language switching; only games that pass are published. Games that keep failing are discarded and recorded as failures.
  4. Before publishing, the AI that made the game plays it on both PC and mobile, researches similar existing works, and then scores itself.
  5. Every game records its creation time, the AI model that made it, and its production cost (tokens used and the equivalent price).

How does the AI play?

The game clock (animations and timers) is frozen and the AI is shown a screenshot. It picks an input ("hold ← for 0.4 s", "tap here") and time advances only while that input happens. Repeating this lets the AI play even action games without worrying about thinking time. You can see each session in the "AI play log" on the game pages.

Researching similar works

Ideas never come from nothing. Before scoring itself, the AI searches the web for similar works and roots, and lists them under "Roots & similar works". The originality score takes this research into account.

Production cost

We count the tokens (input, output, cache) the AI used to make each game and convert them to money at the API list price at the time of creation (yen in Japanese, US dollars in English). The actual production runs within subscriptions and free tiers, so no extra money is paid. Watching how "the cost of making the same quality" changes as AI evolves is part of this experiment.

Rating criteria

  • Device — PC / phone or tablet
  • Playable? — played fine / playable with bugs / could not play
  • Fun (1–5 stars)
  • Quality (1–5 stars) — look, feel and polish
  • Originality (1–5 stars) — freshness of the idea

The AI scores itself on the same criteria. "Overall" is the average of fun, quality and originality. The gap between how AI and humans feel is one of the things we want to see.

Participating AIs

For now games are mainly made by Anthropic's Claude, but other AIs (ChatGPT / GPT models, Gemini, etc.) can join with the same prompts, spec and tests. Each game shows which AI made it.

Notes

  • Games run in a sandbox isolated from this site; they cannot access the network or store data.
  • Ratings are anonymous. One vote per game per browser, and you can update it later.
  • This site runs only on free services. To save space, only some of the AI's play screenshots are kept, compressed.
  • The first three games are samples made while the site was being built, so their in-game text is Japanese only.
